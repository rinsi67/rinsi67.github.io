ClipStudio

A personal desktop tool for recording Twitch streams and publishing short clips.

ClipStudio is a personal desktop application that records the owner's own Twitch live streams, cuts short vertical clips and publishes them to the owner's own social accounts: YouTube Shorts, Telegram and TikTok.

How it works

  • The application runs locally on the owner's computer (Windows) and is not a public service.
  • It records the owner's own broadcast, finds highlights and renders a vertical clip.
  • The owner reviews the clip and the application publishes it through official platform APIs.

TikTok integration

The owner signs in with TikTok OAuth. The application publishes the owner's own clips to the owner's own TikTok profile through the official Content Posting API, using the scopes user.info.basic and video.publish. Access tokens are stored locally on the owner's computer and can be revoked at any time in the TikTok account settings.

There are no user accounts, no third-party data and no tracking in this application.
